# [Jobly Website](https://jobly-frontend-hurv.onrender.com/)

Checkout the deployed website [here](https://jobly-frontend-hurv.onrender.com/)

## Description

Jobly is a fullstack web application that allows users that sign up to apply to jobs that are listed by companies. This site is very simple as it's purpose is to demonstrate fullstack software development skills. 
Users include admins and non-admins. All user can: apply to jobs, edit their accound and search for jobs or companies. Admins have additional capabilites including: viewing all users, adding new users (including admins), editing users, and deleting users. Also admins can add, edit and delete jobs and companies.  

## Additional Details

The backend and frontend are deployed on Render.com and the database is hosted on Supabase. Render.com free tier is used and as such you may experience long loading times.
